가이드 문구

지금 선택된 타입으로 일괄 생성하면 이 가이드 문구가 모든 행에 공통으로 적용됩니다. 수정 후 저장하면 개별 등록 화면에도 동일하게 반영됩니다.

엑셀처럼 입력하기

셀을 클릭해서 직접 입력하거나, 진짜 엑셀에서 범위를 복사한 뒤 첫 칸을 클릭하고 붙여넣기(Ctrl+V)하면 여러 행이 한 번에 채워집니다. 셀을 클릭하면 오른쪽 아래 작은 사각형(채우기 핸들)을 드래그해서 값을 채울 수도 있습니다.

다문제 등록

이 기능은 NPN0(명소), NPM0(길찾기거리) 타입에서만 사용할 수 있습니다. 위에서 타입을 바꿔주세요.

가이드 문구

모든 문제(문제#1, #2, #3...)에 공통으로 이 가이드가 적용됩니다.
가이드 수정/저장은 "개별 등록" 또는 "일괄 등록" 탭에서 해주세요. 여기서는 선택만 가능합니다.

기준지점 (전체 문제 공통)

여기서 한 번만 선택하면, 아래 모든 문제 칸이 같은 기준(명소 또는 출발지)으로 통일됩니다. 바꾸면 그리드가 초기화됩니다.

다문제 일괄 입력

한 행(캠페인) 안에 여러 개의 문제를 만들 수 있습니다. 문제별 칸이 비어있으면 그 문제는 건너뜁니다. 셀 클릭 후 엑셀에서 복사한 내용을 붙여넣기(Ctrl+V) 하면 여러 행이 한 번에 채워집니다.
